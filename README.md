# 勉強記録ツール

資格学習の学習時間を記録・可視化する、単一HTMLファイルのツールです。
ビルド不要・インストール不要・サーバー不要で、ブラウザで開くだけで動きます。

## 使う

https://bajio-dev.github.io/study-log/

スマートフォンのブラウザで開き、「ホーム画面に追加」しておくとアプリのように使えます。

## できること

- 日付・資格・科目・学習時間・理解度・内容・メモの記録
- 資格ごとの目標時間に対する進捗と、期限までに1日あたり何分必要かの自動計算
- 今週・今月・連続学習日数・累計時間のサマリー
- 学習カレンダー（直近20週のヒートマップ）と直近14日の棒グラフ
- 科目別の積み上げ時間と構成比
- 記録の検索・編集・削除
- CSV / JSON での書き出しと読み込み

## データの保存場所

記録は**開いているブラウザの localStorage にのみ**保存されます。
サーバーには一切送信されないため、このリポジトリが公開されていても記録が外部に出ることはありません。

その代わり、**ブラウザのデータを消すと記録も消えます。** 週に1度は「CSVで書き出す」でバックアップしてください。
また端末ごとに別々のデータになるため、記録する端末は1台に決めることをおすすめします。

## カスタマイズ

対象資格・目標時間・期限・科目一覧は、`index.html` 内の `const CERTS = [...]` を編集すると変更できます。

```js
const CERTS = [
  { key:"資格名", color:"var(--c1)", targetH:30, deadline:"2026-08-26",
    subjects:["科目1","科目2"] },
];
```

週あたりの目標時間は `const WEEKLY_TARGET_H = 14;` で変更します。
